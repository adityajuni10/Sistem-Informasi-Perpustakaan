# Deskripsi Sistem Informasi Perpustakaan

## Nama Sistem
Sistem Informasi Perpustakaan

## Tujuan
Sistem ini digunakan untuk membantu proses pengelolaan perpustakaan agar lebih terstruktur, cepat, dan efisien.

Sistem dapat digunakan untuk mengelola:
- Data mahasiswa
- Data petugas
- Data buku
- Data peminjaman
- Detail peminjaman

## Pengguna Sistem
Pengguna sistem terdiri dari:
- Mahasiswa
- Petugas perpustakaan
- Admin

## Data yang Dikelola
Data yang dikelola dalam sistem meliputi:
- NIM dan data mahasiswa
- ID dan data petugas
- Data buku seperti judul dan penulis
- Data transaksi peminjaman
- Detail buku yang dipinjam

## Manfaat Sistem
Sistem Informasi Perpustakaan membantu proses pencatatan menjadi lebih cepat, rapi, dan mudah dikelola. Sistem juga dapat mengurangi kesalahan pencatatan dan mempermudah pencarian informasi.
