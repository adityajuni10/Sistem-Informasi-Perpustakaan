# Cloud Computing pada Sistem Informasi Perpustakaan

## a. Nama Sistem Informasi
Sistem Informasi Perpustakaan.

## b. Tujuan Sistem Informasi
Sistem Informasi Perpustakaan bertujuan untuk membantu proses
pengelolaan perpustakaan agar lebih terstruktur, cepat, dan efisien.

Sistem ini digunakan untuk mengelola data mahasiswa, petugas,
buku, serta transaksi peminjaman buku.

## c. Pengguna Sistem
Pengguna Sistem Informasi Perpustakaan terdiri dari:

- Mahasiswa atau anggota perpustakaan
- Petugas perpustakaan
- Admin sistem

Mahasiswa menggunakan sistem untuk melakukan aktivitas yang
berhubungan dengan peminjaman buku, sedangkan petugas dan admin
mengelola data serta transaksi perpustakaan.

## d. Jenis Informasi yang Dikelola
Informasi yang dikelola dalam sistem meliputi:

- Data mahasiswa
- Data petugas
- Data buku
- Data peminjaman
- Detail peminjaman buku

Data tersebut disimpan dalam database agar lebih mudah dikelola,
dicari, dan diperbarui.

## e. Kebutuhan Sistem terhadap Layanan Cloud Computing
Sistem Informasi Perpustakaan membutuhkan layanan cloud computing
agar aplikasi dan database dapat disimpan pada server yang dapat
diakses melalui jaringan internet.

Cloud computing dapat digunakan untuk:

- Menyimpan database perpustakaan
- Menjalankan aplikasi sistem informasi
- Melakukan backup data
- Mendukung akses dari berbagai perangkat
- Melayani beberapa pengguna secara bersamaan

Dengan cloud computing, sistem tidak hanya bergantung pada satu
komputer yang berada di perpustakaan.

## f. Manfaat Cloud Dibandingkan Penyimpanan Komputer Lokal
Penggunaan cloud computing memiliki beberapa manfaat dibandingkan
penyimpanan hanya pada komputer lokal, yaitu:

1. Data dapat diakses dari berbagai perangkat dan lokasi.
2. Data tersimpan secara terpusat.
3. Mempermudah proses backup data.
4. Mengurangi risiko kehilangan data akibat kerusakan komputer lokal.
5. Dapat digunakan oleh beberapa pengguna secara bersamaan.
6. Kapasitas penyimpanan dapat ditambah sesuai kebutuhan.

## Kesimpulan
Penggunaan cloud computing pada Sistem Informasi Perpustakaan
membantu proses penyimpanan dan pengelolaan data menjadi lebih
fleksibel, terpusat, dan mudah diakses.

Cloud computing juga mengurangi ketergantungan sistem terhadap
satu komputer lokal serta mempermudah proses backup dan
pengembangan sistem di masa depan.
